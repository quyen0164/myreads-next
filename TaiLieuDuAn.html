Tài liệu Đặc tả Kỹ thuật & Phân tích Dự án

Dự án: MyReads - Hệ thống quản lý thư viện cá nhân

PHẦN 1: PHÂN TÍCH DỰ ÁN (TECHNICAL ANALYSIS)

1. Kiến trúc hệ thống (System Architecture)

  • Mô hình: Monolithic Architecture (Nguyên khối) sử dụng Next.js App Router.
  • Rendering Model: Kết hợp RSC (React Server Components) cho phần hiển thị dữ liệu tĩnh và CSR (Client Components) cho các phần tương tác (Form, Modal, Autocomplete).
  • Data Fetching & Mutation: Sử dụng Next.js Server Actions (RPC-style) thay vì RESTful API truyền thống. Giúp giảm thiểu boilerplate code.
  • Database: SQLite (thông qua thư viện better-sqlite3 chạy đồng bộ).
  • Authentication: Sử dụng Cookie-based Session. Lưu trữ JSON (id, role) trong cookie httpOnly để chống tấn công XSS.

2. Cơ chế Bảo mật (Defense in Depth)

  • Lớp 1 (Edge/Middleware): middleware.ts chặn các request không hợp lệ tới /admin.
  • Lớp 2 (Server Component): AdminGuard xác thực lại quyền ADMIN trước khi render giao diện hoặc gọi DB. Nếu Middleware bị bypass, Guard vẫn bảo vệ trang.
  • Lớp 3 (Server Action): Các action nhạy cảm gọi getCurrentUserId() để kiểm tra tính hợp lệ của phiên và ràng buộc Khóa ngoại (FK constraint) trước khi ghi vào DB.

PHẦN 2: ĐẶC TẢ YÊU CẦU (SOFTWARE REQUIREMENTS SPECIFICATION)

1. Yêu cầu chức năng (Functional Requirements)

ID Chức năng Tác nhân Mô tả chi tiết
FR-01 Đăng nhập / Đăng xuất Tất cả Đăng nhập bằng email (không password). Lưu session vào cookie. Logout xóa cookie và điều hướng về trang chủ.
FR-02 Tìm kiếm sách Tất cả Tìm kiếm theo Tên sách, ISBN, hoặc Tên tác giả. Trạng thái tìm kiếm được lưu trên URL (?q=...).
FR-03 Đổi kệ sách User Gắn sách vào kệ cá nhân: want_to_read, reading, read.
FR-04 Viết / Sửa đánh giá User Đánh giá sách (1-5 sao + bình luận). Nếu đã đánh giá, thao tác sẽ ghi đè (Upsert).
FR-05 Quản lý Sách (CRUD) Admin Thêm, sửa, xóa sách. Xử lý ảnh bìa (URL hoặc Upload + resize Canvas).
FR-06 Quản lý Danh mục (CRUD) Admin Thêm, sửa, xóa Tác giả và Thể loại. Chặn trùng lặp (UNIQUE constraint).
FR-07 Quản lý Người dùng Admin Thêm, sửa role, xóa người dùng.
FR-08 Quản lý Đánh giá Admin Xem, sửa số sao/nội dung, xóa review của bất kỳ ai.
